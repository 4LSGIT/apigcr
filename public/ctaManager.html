How CTA links work

A CTA ("call to action") is a tokenized link that runs a pre-authorized set of actions when the recipient picks an option and confirms. Each option carries a plan — the same internal functions workflows use. Plans are frozen when you mint: a click can never change what happens, only whether it happens. Links live on the public host at 4lsg.com/c/<token>; every emailed button opens a confirm page first.

once (default): the first confirmed click wins; an optional timeout option runs by itself at expiry if nobody clicks. repeatable: every click runs the plan until expiry or a max_uses cap — standing actions, or live lookup links with a result template.

Protection: none — anyone holding the link can execute; password — the confirm page asks for a secret. A generated password is shown once, at mint. Links that return information default to password. Never a YisraCase account password.

Clicker inputs: an option can ask the clicker for values — a phone number, a message, a choice from a list — and pass each one into its plan as a step param's whole value, [[input:name]]. Only params a function opens to clicker input can take one (the step shows which). The server validates every value and escapes text that lands in an email body. Inputs make the default protection password; a reusable link where the clicker picks the recipient needs a use cap, and the risky shapes ask for an explicit acknowledgment.

Lifecycle: links always expire — extend instead of re-minting. Disable is the kill switch (reversible). Re-enabling a used link whose plan failed re-runs the whole plan on the next click. Cancel is permanent. Stored states are active / used / disabled / cancelled; expired and exhausted are derived from the expiry and the use cap.

Results: every click is an execution below, with the full per-step plan output — that detail is SU-only. Recipients see only success/failure, plus the option's result template text. Workflow-minted links (create_cta) show here with source "workflow". Manual: Admin Tools → CTA Links.
