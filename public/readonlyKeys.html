Create a session key

A session key lets a script or an AI session reach only the surfaces in its scopes. The key starts ycro_; it is shown once, here, and never stored.
Default 1440 min (1 day). Max 3 days.
Scopes:
temp.* scopes call an external provider (Clio, Dropbox, RingCentral, Zoho Sign) with the firm's credentials — grant one only for the task at hand.
keys.mint makes a manager key: it can mint its own child keys for the sessions it runs (sql.ro / scratch / alert only, at most 24h, never past this key, and dead the moment this key is).
The sensitive scope lets the key read call transcripts, AI prompts and replies, and every audit log — including other sessions' SQL. Short-lived by rule: at most 24h, default 4h.
